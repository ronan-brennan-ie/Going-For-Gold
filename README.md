# Going For Gold

A mobile-friendly, unofficial quiz game inspired by the classic TV quiz format.

## Play

Open `index.html` in a browser, or enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Once published, the site should be available at:

https://ronan-brennan-ie.github.io/Going-For-Gold/

The game includes four rounds, timed multiple-choice questions, three simulated opponents, scoring, and a replay option. It works without a backend or dependencies.

This is an unofficial fan-made project and is not affiliated with the original programme or rights holders.
